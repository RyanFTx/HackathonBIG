# HackathonBIG

## Getting Started

This project is a Slither.io-style language learning game built with JavaScript and Vite.

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1. Open a terminal in the `snakelang` directory:
   ```sh
   cd snakelang
   ```
2. Install dependencies:
   ```sh
   npm install
   ```

### Running the Game

1. Start the development server:
   ```sh
   npm run dev
   ```
2. Open your browser and go to the URL shown in the terminal (usually [http://localhost:5173](http://localhost:5173)).

### Project Structure

- `snakelang/src/` — Main game source code
- `snakelang/public/` — Static assets (images, translations)
- `snakelang/index.html` — Entry HTML file

### Troubleshooting

- If you see errors, make sure Node.js and npm are installed and up to date.
- For issues with assets or translations, check the `public/assets/` and `public/assets/translations/` folders.

---

Enjoy learning languages while playing!
